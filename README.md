## Funcionalidades

- Registro de libros con título, autor e ISBN.
- Visualización del inventario de libros.

## Cómo utilizar el sistema

1. Completar el formulario con los datos del libro.
2. Presionar el botón **Registrar libro**.
3. Comprobar que el libro aparezca en la tabla de inventario.

> Este sistema fue desarrollado para facilitar la administración de libros de una biblioteca utilizando PHP, MySQL, HTML5, CSS3 y JavaScript.

## Estructura del proyecto

- `index.php` — Página principal con el formulario y el inventario.
- `guardar.php` — Procesa y guarda los nuevos libros.
- `script.js` — Valida los datos del formulario.
- `styles.css` — Contiene los estilos de la aplicación.


## Tecnologías utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
